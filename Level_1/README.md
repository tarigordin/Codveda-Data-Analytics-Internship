# Level 1: Basic Data Analytics

This directory contains the completed tasks for **Level 1** of the Data Analytics Internship at Codveda Technology.

---

## 📌 Tasks Completed

### Task 1: Data Cleaning and Preprocessing
- **File:** `Codveda_Level_1_Task_1_Data_Cleaning.ipynb`
- **Activities:**
  - Loaded raw telecom customer churn dataset using `pandas`.
  - Checked for missing values, duplicates, and inconsistent types.
  - Standardized feature formats and variable encodings.
  - Exported the preprocessed dataset as `churn_cleaned.csv`.

---

### Task 2: Exploratory Data Analysis (EDA)
- **File:** `Codveda_Level_1_Task_2_EDA.ipynb`
- **Activities:**
  - Computed summary statistics including mean, median, mode, and standard deviation.
  - Plotted distribution histograms to analyze feature spread.
  - Utilized boxplots for outlier detection across customer service calls and usage metrics.
  - Generated correlation heatmaps and examined pairwise relationships between call duration, charges, and churn.

---

## 🔍 Key Insights & Findings
- **Baseline Churn Rate:** Approximately **14.24%** of customers churned.
- **Service Inquiries:** Customers with 4 or more customer service calls exhibited a sharp increase in churn probability ($r \approx 0.233$).
- **Usage Patterns:** Churned customers logged higher average daytime usage minutes and charges ($r \approx 0.243$).
- **Subscription Plans:** Customers enrolled in the International Plan displayed significantly higher churn rates compared to standard users.
