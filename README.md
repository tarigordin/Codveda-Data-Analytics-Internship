# Codveda Technology - Data Analytics Internship

This repository contains the tasks and projects completed during the Data Analytics Virtual Internship at **Codveda Technology**.

---

## 📌 Project Overview
The internship requires completing two tasks per level across three progressive analytical tiers:
- **Level 1 (Basic):** Data Cleaning, Preprocessing & Exploratory Data Analysis (EDA)
- **Level 2 (Intermediate):** Regression Analysis & Machine Learning Clustering ($K$-Means)
- **Level 3 (Advanced):** Predictive Modeling (Classification) & Business Intelligence Dashboards
## 📊 Dataset Information
- **Dataset:** Telecom Customer Churn Dataset (`churn-bigml-20.csv`)
- **Records:** 667 rows, 20 features
- **Target Variable:** `Churn` (True / False)
- **Key Features:** Usage minutes/charges across day, evening, night, and international calls, customer service calls, and subscription plans.
